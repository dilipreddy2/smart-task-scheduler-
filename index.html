What is Smart Task Scheduler?

People have many tasks but limited time. This application helps users schedule their daily tasks based on deadlines and priority scores.

It compares four algorithmic approaches to find a schedule that maximizes the total priority score.

Objective: Complete as many valuable tasks as possible without missing their deadlines.

06. Algorithm Complexity

Algorithm Time Complexity Space Complexity
Brute Force O((D+1)ⁿ) O(n + D)
Greedy O(n log n + nD) O(n + D)
Dynamic Programming O(n × 2ⁿ) O(n × 2ⁿ)
Backtracking O((D+1)ⁿ) O(n + D)

n = Number of tasks. D = Maximum scheduling day, capped at n. Exhaustive algorithms are intended for small inputs.
