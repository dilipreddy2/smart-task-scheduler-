# Smart Task Scheduler Using Four Algorithmic Approaches

## 📌 Project Overview
Smart Task Scheduler is a web-based application that helps users schedule tasks based on their deadlines and priorities. It uses four different algorithmic approaches to find and compare task schedules.

## 🎯 Objectives
- Organize tasks based on deadlines and priorities.
- Maximize the total priority score of completed tasks.
- Implement four algorithmic approaches.
- Compare the performance and results of different algorithms.

## 🧠 Algorithms Used
1. **Brute Force:** Explores possible task schedules to find the best solution.
2. **Greedy Algorithm:** Selects tasks based on their priority and available deadlines.
3. **Dynamic Programming:** Uses previously computed results to find an optimal schedule.
4. **Backtracking:** Explores possible schedules and prunes branches that cannot improve the result.

## ✨ Features
- Add and manage tasks.
- Set task deadlines and priorities.
- Generate schedules using four algorithms.
- Compare algorithm results.
- Display total priority scores.
- Responsive and user-friendly interface.
